# Flak Defense

A WebXR anti-aircraft battlefield game for Meta Quest (also playable on desktop and mobile).

**Play:** https://nag-fdestech.github.io/flak-defence/

- **Quest:** open the link in the Quest Browser and tap **Enter VR**. Point a controller and hold the trigger to fire. A/X reloads, B/Y recenters your seat.
- **Desktop:** click to aim with the mouse, hold to fire, R reloads.

Shoot down enemy fighters and bombers. Friendly planes (blue markers) drop health, ammo and upgrade crates. Don't shoot them.

Everything (models, textures, sound) is generated in code; the only dependency is three.js from a CDN.
